## 阅读方式

可直接在 GitHub 上浏览，也可使用支持 Markdown 和 LaTeX 数学公式的编辑器阅读。内容用于个人学习与复习，持续补充和修订。

## 一键提交并推送

在本机任意目录执行：

```bash
bash "$HOME/桌面/nju-class/push.sh"
```

在仓库目录内也可以执行：

```bash
./push.sh
```

自定义本次提交说明：

```bash
./push.sh "补充数学分析课堂笔记"
```

脚本会将仓库内所有未被 `.gitignore` 忽略的新增、修改和删除加入版本控制；有改动时自动提交，随后推送当前分支到 `origin`。默认提交说明包含时间；无改动时也会尝试推送尚未上传的提交。需要本机安装 Git，并具备该 GitHub 仓库的访问权限。

若远端存在本地尚未合并的提交，推送会停止并显示错误；先处理远端更新再重新执行脚本。
