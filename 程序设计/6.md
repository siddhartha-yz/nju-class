根据教材脉络和这次转写，这节考点主要集中在“C++特点、程序组成、编译运行流程、开发环境”。

1. C++ 标准【了解/选择题】

C++ 有统一的国际标准，避免不同编译器对语言理解不一致。老师特别强调：

$\boxed{\text{C++11 是现代 C++ 的重要分界点}}$

C++11 之前常称传统 C++，C++11 之后进入现代 C++。

1. C++ 的主要特点【概念题】

优点：

- 应用范围广；
- 灵活；
- 执行效率高；
- 能进行较底层的操作。

缺点：

- 灵活也意味着更容易写错；
- 安全检查较少；
- 对程序员要求较高。

例如数组下标越界，C++ 通常不会替你自动做全面检查，因此正确性更多由程序员保证。

一句话：

$\boxed{\text{C++：高效、灵活，但程序员责任更大}}$

1. 本课程重点不是“背 C++”【理解】

课程真正目标是学习通用的：

$\boxed{\text{程序设计思想 + 概念 + 技术}}$

C++ 只是用来落实这些思想的工具。

1. C++ 程序的基本实体【记忆】

程序中会出现：

- 常量：不变的数据；
- 变量：可变的数据；
- 函数：完成某种功能的子程序；
- 数据类型；
- 面向对象程序中还有对象、类等。

特别注意：

$\boxed{\text{C++ 中的函数}\neq\text{数学函数}}$

C++ 函数可能因为程序状态不同，同样调用得到不同结果。

1. `main` 函数【★★★ 必考】

每个 C++ 程序：

$\boxed{\text{有且仅有一个 main 函数}}$

程序从 `main` 开始执行。

1. 最基本程序结构【会读代码】

这一阶段至少会看懂：

```cpp
#include <iostream>
using namespace std;

int main() {
    double x, y;
    cin >> x >> y;

    double z = x + y;
    cout << z;

    return 0;
}
```

核心流程就是：

$\boxed{\text{定义变量}\to\text{输入}\to\text{计算}\to\text{输出}}$

`cin` 输入，`cout` 输出。

1. 运算符与注释【基础题】

- 乘法：`*`
- 除法：`/`
- 单行注释：`//`

注释是给人看的，编译时不参与程序执行；良好的程序应适当写注释，方便阅读和维护。

1. 一个程序可以由多个文件组成【概念题】

小程序可以只有一个文件；大型程序通常拆成多个模块：

$\boxed{\text{一个模块}\approx\text{一个源文件}}$

但整个程序仍然只能有一个 `main`。

1. C++ 程序从源码到运行【★★★ 最重要】

完整流程：

$\boxed{\text{编辑}\to\text{编译}\to\text{链接}\to\text{运行}}$

Windows 下课堂对应：

$\boxed{ \text{.cpp} \xrightarrow{\text{编译}} \text{.obj} \xrightarrow{\text{链接}} \text{.exe} }$

- `.cpp`：C++ 源程序；
- `.obj`：目标代码文件；
- `.exe`：最终可执行文件。

多个 `.cpp` 时：

$\text{多个 .cpp}\to\text{多个 .obj}\to\text{链接成一个 .exe}$

链接阶段还要把程序需要的标准库等代码组合进来。

1. IDE 与调试【实践题】

IDE 把：

$\boxed{\text{编辑 + 编译 + 链接 + 运行 + 调试}}$

集成起来。

调试常用：

- 断点 breakpoint；
- 查看变量当前值；
- 单步执行。

最该背：

$\boxed{ \begin{gathered} \text{C++：灵活、高效，但安全责任更多交给程序员}\\ \text{程序有且仅有一个 main，从 main 开始执行}\\ \text{基本流程：输入}\to\text{计算}\to\text{输出}\\ \text{.cpp}\to\text{编译}\to\text{.obj}\to\text{链接}\to\text{.exe}\\ \text{IDE：编辑+编译+链接+运行+调试} \end{gathered}}$

这节最可能直接考的就是：**`main`、`.cpp/.obj/.exe` 区别、编译和链接的区别、C++ 的优缺点、断点/单步调试。**
