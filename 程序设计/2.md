这节《程序设计基础》重点极简版：

- IDE 红色波浪线 = 代码大概率有错；要学会看编译报错，尤其是行号、`error`、`expected` 等关键词。
- OJ 不只要求“逻辑差不多对”，而是输出必须和题目要求完全一致：大小写、感叹号、多余提示文字都可能导致错误。
- C++ 基本框架先当模板记：

```cpp
#include <iostream>
using namespace std;

int main() {
    ...
}
```

所有程序都从 `main` 开始。

- 变量：用于存数据。`double` 存小数，`int` 存整数。
- 输入输出：
  - `cin >> x;`：键盘/输入 → 变量
  - `cout << x;`：变量/数据 → 屏幕
    `>>`、`<<` 可以理解成数据流动方向。
- `=` 在 C++ 里是“赋值”，不是数学里的等号：

```cpp
z = x + y;
```

意思是“把 `x+y` 的结果存进 `z`”。

- 编程符号必须用英文半角，中文分号、引号、空格可能导致编译错误。
- 上机考试只能在课程网站环境里做，不能依赖 IDE；所以平时要练习直接看网站的编译错误。

一句话：

**这节课核心就是：会写最基本 C++ 框架，理解变量、`cin/cout`、赋值，并学会按 OJ 要求精确输出和自己看报错。**
